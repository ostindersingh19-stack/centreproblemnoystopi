# Центр стопы

Статический сайт центра подологии и ухода за стопами.

## Структура

- корневые `*.html` — страницы сайта и их уникальный контент;
- `partials/` — исходники общих header, CTA и footer;
- `css/style.css` — базовый слой стилей;
- `css/refined.css` — общая визуальная и responsive-полировка;
- `css/pages.css` — стили страниц и компонентов;
- `js/script.js` — меню, accordion, accessibility и image behavior;
- `images/` — изображения;
- `scripts/build.js` — сборка общих блоков и image attributes.

## Сборка

Редактируйте общие header, CTA и footer только в `partials/`, а уникальные тексты и блоки — в соответствующих HTML-файлах. Выполните:

```bash
npm run build
```

Сборка обновляет общие блоки в корневых HTML-файлах, добавляет атрибуты изображений и выставляет активный пункт навигации. Корневые HTML одновременно являются исходниками страниц и готовым результатом для публикации; отдельная `dist`-папка не используется.

Не меняйте без отдельного согласования тексты, цены, URL и смысловой порядок главной страницы. Карточки «Подология», «Массаж» и «Стельки» должны оставаться одним из первых блоков главной.
