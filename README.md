# Центр стопы

Статический сайт центра подологии и ухода за стопами.

## Правила работы с проектом

- Не менять тексты, названия услуг и URL страниц без отдельного согласования.
- На главной странице карточки основных услуг должны оставаться одним из первых блоков страницы.
- Общую визуальную концепцию сохраняем: спокойный, чистый, современный минимализм.
- Перед крупными изменениями проверять главную, цены, контакты и несколько страниц услуг на desktop и mobile.

## Структура

- `*.html` — страницы сайта
- `css/style.css` — основные стили
- `js/script.js` — интерактивность
- `images/` — изображения

## Технический долг

Сайт пока не использует шаблонизатор, поэтому header/footer/CTA физически повторяются в HTML-файлах. Это можно вынести в partials на отдельном этапе, не меняя концепцию сайта.
